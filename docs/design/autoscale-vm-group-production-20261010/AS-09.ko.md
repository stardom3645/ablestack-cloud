# AS-09 / #1355 Mold VM UI 표준 통합 설계

Epic #1346의 기존 기능을 현재 Mold에 통합한다. AS-01~07 API/평가/복구/프로필/예약/조회 계약은 유지하며 별도 대시보드나 UI를 만들지 않는다.

## 공통 탭과 전용 정보의 경계

공통 첫 상세 탭은 자원 속성 목록만 담당한다. 여기에 들어간 오토스케일 운영 요약·정책 평가·작업 알림을 제거한다. 이미 같은 요약·평가가 있는 전용 **운영 상태** 탭으로 단일화한다. 삭제 재시도·드레인·비활성화 후 정리 알림은 그 요약 안에서 표시한다. 새로운 요약 탭을 추가하지 않는다.

**EventsTab / AnnotationsTab 소스·탭 설정·형식은 그대로 유지**한다. 운영 상태의 최근 5개 이벤트는 기존 AS-07 조회 기능이며 공통 이벤트 탭을 대체하지 않는다. 모든 권한 판정과 부분 조회 실패/이전 기록 표시는 유지한다.

## 목록·왼쪽 요약

기존 ResourceLayout / InfoCard / ListView / 상태 표시 / 검색·정렬·선택·페이지를 재사용한다. 오토스케일 경로에서만 멤버(조정 대상 수와 최소·최대), 네트워크(LB 공인 IP와 공인→게스트 포트), 최근 확인(평가/작업 상태)을 묶어 표시한다. 기존 저장 열 선택은 새 열로 변환하며 API 원본 값은 바꾸지 않는다. 계정·프로젝트 범위는 기존 계약을 따른다. 왼쪽 공통 카드의 기존 details 슬롯에만 해당 그룹의 범위·포트·확인 시각을 추가한다. 다른 자원의 슬롯 출력은 비어 있으며 공통 카드 본문은 수정하지 않는다.

## 전용 탭·대화상자·생성

VM에서 사용 중인 mold-dialog 셸과 테마 토큰을 적용한다. 긴 폼의 확인/취소는 스크롤 본문과 분리한 고정 footer에 배치한다. 기존 프로필·정책·LB 변경의 권한·작업 중 차단·최신 상태 확인·공유 영향/실패 보상 로직을 유지한다. 기본 텍스트 작업 버튼이 먼저 나오고 보조 아이콘이 뒤따른다. 생성은 기존 VM 방식의 폼/요약 카드와 단계별 결과를 유지하고 그룹 범위·간격·LB 포트와 호스트 이름 제한을 최종 요약에 추가한다. UserData 원문·인증 정보를 요약에 노출하지 않는다.

재조정 대기 시간(초), 조건 추가, 조정 대상 VM 용어는 오토스케일 전용 키로 교정한다. 공통 이벤트·코멘트·다른 자원 번역은 변경하지 않는다.

UI 변경만 빌드/배포한다. Cloud Java 변경이 없으므로 Maven/전체 Cloud 빌드는 실행하지 않는다. 배포 시 WEB-INF/META-INF/config.json/PID를 보존하고 정적 파일 SHA 및 /client/ 200을 검증한다. GitHub Actions 전체 CI와 장시간 운영은 본 이슈 검증 결과에 포함하지 않는다. #1354에서 통합 검증 후 최종 장시간 확인을 수행한다.
