# #1210 볼륨 연결 VM 표시이름 검색 설계

- 범위: 스토리지 > 볼륨 > 가상머신 연결의 AttachVolume.vue. 백업 복구 연결 API 대화상자는 별도 흐름이다.
- 원인: vm.name 우선 표시와 검색으로 표시이름 변경이 반영되지 않았다. Running/Stopped API도 첫 페이지만 합치고 한 요청 종료만으로 로딩을 해제했다.
- 후보 표시: 표시이름 우선, 이름·인스턴스 이름·UUID를 보조 행에 표시한다. 같은 표시이름도 UUID로 구분하며 선택 값과 attachVolume 요청은 UUID를 사용한다.
- 검색: 앞뒤 공백과 대소문자를 정규화해 표시이름·이름·인스턴스 이름·UUID에서 검색한다. 기존 검색도 유지한다.
- 조회: 원래 볼륨의 zone/hypervisor/owner 또는 project 범위를 보존한다. Running/Stopped 각각 API 전체 페이지를 조회한 뒤 원자적으로 교체한다. 일부 페이지 실패는 완료된 목록으로 취급하지 않는다.
- 오류/동시성: 오류 표시와 대화상자 내 재시도, 기존 선택 보존, 실패·조회 중 제출 차단. 소유자·사용자·프로젝트 전환과 오래된 응답을 차단한다.
- 제출: 동일 소유자 범위에서 선택한 UUID를 다시 조회하고 현재 상태·소유자·백업 제한을 검사한다. 표시이름을 식별자로 사용하지 않는다.
- 빌드/검증: UI 변경만 빌드한다. 단위검증, 31/32 실제 브라우저 검색·연결, API/DB/스토리지 증거, 전용 자원 정리와 기존 운영 자원 보존을 확인한다.
